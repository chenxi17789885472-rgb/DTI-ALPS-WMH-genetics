# STREGA reporting checklist — manuscript mapping

This working checklist follows the STREGA extension of STROBE for genetic-association studies. Page numbers should be added after journal-specific typesetting.

| Reporting item | Manuscript location | Status |
|---|---|---|
| Identify the genetic-association/imaging-genetics design | Title; Abstract; Methods—Study design | Complete |
| Scientific background and rationale | Introduction | Complete |
| Objectives and hypotheses | End of Introduction | Complete |
| Study design and contributing data sources | Methods—Study design; Table 1; Supplementary Table 13 | Complete |
| Participant selection and ancestry in contributing studies | Methods—DTI-ALPS phenotypes and source GWAS; Table 1 | Complete from published sources |
| Phenotype definitions and measurement | Methods—DTI-ALPS phenotypes and source GWAS; Figure 1 | Complete |
| Genotyping, imputation, and source-GWAS quality control | Methods; Supplementary Table 1 | Complete at summary-statistics level |
| Variant selection and locus definition | Methods—Genome-wide significant variants and locus definition | Complete |
| Population stratification and relatedness handling | Source-GWAS description; Supplementary Table 1 | Complete from source study |
| Statistical methods, multiplicity, and model assumptions | Methods; parameter locks; Supplementary Tables 2–7 | Complete |
| Hardy–Weinberg, call rate, MAF, and imputation thresholds | Methods; Supplementary Table 1 | Complete from source study |
| Treatment of missing, duplicate, ambiguous, and palindromic variants | Methods; harmonization audits | Complete |
| Relatedness and ancestry of LD reference | Methods—Multi-signal fine-mapping | Complete |
| Sample overlap and correlated estimation error | Abstract; Methods; Results; Discussion; Figure 5 | Complete and explicit |
| Winner selection/data-dependent regional follow-up | Methods; Results; Discussion; Figure 5 | Complete and explicit |
| Main and sensitivity results | Results; Tables 1–2; Figures 2–6; Supplementary Tables | Complete |
| Replication or external evaluation | Results—Non-UK Biobank evaluation; Discussion | Complete; negative result reported |
| Limitations and generalizability | Discussion | Complete |
| Data and code availability | Data Availability; Code Availability; reproducibility release | Local package complete; public URL/DOI pending |
| Funding and conflicts | End matter | Author action pending |

Official source: EQUATOR Network STREGA reporting guideline and Little et al., *Human Genetics* 2009.
